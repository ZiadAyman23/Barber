# 💈 Barbershop Management System

A full-stack Barbershop Management System built with ASP.NET Core Web API and Blazor Web App.

## 🚀 Features

- Authentication & Authorization
- Barber Management
- Order Management
- Salary Management
- Attendance Management
- Deduction Management
- Expense Management
- Item & Service Management
- Search & Filtering
- Pagination
- JWT Authentication
- Refresh Tokens

## 🛠️ Technologies

- C#
- ASP.NET Core Web API
- Blazor Web App
- .NET 10
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- JWT
- Bootstrap
- JavaScript
- Swagger
